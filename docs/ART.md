# 本地美术资源

所有运行时图片均包含在 assets/ 内，不依赖网络、字体服务或运行时生成。

| 文件 | 用途 |
| --- | --- |
| restaurant-portrait.png | 固定9:16斜俯视饭馆环境 |
| dining-table.png | 独立透明桌椅，按桌位大小与朝向放置 |
| dishes-atlas.png | 12道菜，4列×3行 |
| guests-atlas.png | 6类顾客站姿，3列×2行，用于排队和行走 |
| guests-seated-atlas.png | 6类顾客坐姿，3列×2行，用于落座和用餐 |
| props-atlas.png | 五种礼物和灶台，3列×2行 |
| favicon.svg | 项目标识 |

上述PNG由内置AI生图工具生成，作为项目静态素材使用；没有使用第三方付费素材库或运行时API。图集透明度与网格尺寸由自动化测试检查。图标、UI、引导线和布局由HTML/CSS/SVG实现。

桌位、桌椅落点、人物臀部/脚底锚点、餐碗及进出场路径统一定义在 src/scene-layout.js。正式规则开放3/4/5桌，额外坐标仅供未来扩展，不增加当前等级桌数。坐姿使用每类顾客的臀部锚点贴合凳面；左右桌镜像，人物朝向桌面。站姿按脚底定位，中央排队点间隔40逻辑像素。

动效只读取状态变化，不参与计时、随机奖励、出餐或结账。关闭动态效果、静音和系统减少动态偏好不改变经营结果。
